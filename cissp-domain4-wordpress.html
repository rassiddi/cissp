Exam tip: Most protocols starting with "I" are Layer 3 — IP, ICMP, IGMP, IGRP, IPSec, IKE, ISAKMP. IMAP is the exception — it works at Layer 7. Routers = Layer 3. Switches = Layer 2. Hubs = Layer 1.
Layer details — tap to expand
Layer 1 — Physical
Converts frames to bits (encapsulation going down) and bits back to frames (decapsulation going up). Deals with cables, voltage, hubs, signals. Twisted pair = least secure, cheapest. Fibre optic = most secure, most expensive. Topologies: Bus, Ring, Star (switch = single point of failure), Mesh (most fault-tolerant).
Layer 2 — Data Link
Converts packets to frames. LLC (Logical Link Control) handles error detection. MAC (Media Access Control) uses physical hardware addresses. ARP maps IP → MAC. RARP maps MAC → IP. Access methods: CSMA/CD (IEEE 802.3 Ethernet — collision detection), CSMA/CA (IEEE 802.11 wireless — collision avoidance), Token Passing (no collision — system needs token to transmit).
Layer 3 — Network
Adds routing and addressing. Does NOT guarantee delivery (that's Layer 4). Routers isolate broadcast domains. Switches used for VLAN-based broadcast isolation (cheaper than routers). Layer 3 switch needed for inter-VLAN communication. Routing: Distance Vector (BGP, RIP, IGRP — direction + hops), Link State (OSPF — shortest path).
Layer 4 — Transport
End-to-end data transport and logical connections. TCP = connection-oriented, reliable, slow (3-way handshake: SYN→SYN-ACK→ACK). UDP = connectionless, fast, unreliable (streaming, gaming, DNS). SYN flood attack exploits the 3-way handshake. Fraggle attack uses UDP. SSL/TLS spans Layers 4–7.
Layer 5 — Session
Establishes, manages and terminates sessions between applications. Create → Transfer → Release. Simplex: one-way only. Half Duplex: both ways but not simultaneously. Full Duplex: both ways simultaneously. Protocols: RPC, NFS, SQL, NetBIOS.
Layer 6 — Presentation
Formats data for the application layer. Handles: Formatting (JPEG, GIF, MP3), Encryption/Decryption, Compression (removes redundancy). No specific protocols — it is a translation service. SSL/TLS encryption can operate here.
Layer 7 — Application
Defines protocols for application-to-application communication. HTTP (80), HTTPS (443), FTP (20/21), SFTP (22), SMTP (25), POP3 (110), IMAP (143), DNS (53), SNMP (161), Telnet (23), SSH (22), LDAP (389). Proxy firewalls operate at this layer.
Port ranges
Well-known ports: 0–1023 (assigned by IANA). Registered ports: 1024–49151 (registered software). Dynamic/Ephemeral ports: 49152–65535 (random/temporary). TCP Wrapper = application that acts like a firewall restricting access to ports based on user/system IDs (port-based access control).
Network devices by OSI layer
Layer 1
Hub, Repeater, Modem
Hub sends all data to all ports — no addressing, creates collisions
Layer 2
Switch, Bridge
Switch uses MAC address to direct traffic, reduces collisions. Bridge connects two different network types.
Layer 3
Router
Connects similar networks, routes by IP address. Isolates broadcast domains.
Layer 4–7
Gateway, Proxy
Gateways connect networks using different protocols. Proxy inspects application-layer traffic.
VLAN
Virtual LAN
Logically segments a network without altering physical topology. Layer 3 switch required for inter-VLAN routing.
WAP
Wireless Access Point
Connects wireless devices to the wired network. Rogue APs enable MITM attacks.

Converged protocols
FCoE — Fibre Channel over Ethernet
Allows high-speed (16 Gbps) Fibre Channel storage traffic to run over standard Ethernet networks. Works at Layer 3. Used as a network data storage solution — eliminates the need for separate storage networks.
iSCSI
Internet Small Computer System Interface. Enables location-independent file storage and retrieval over LAN, WAN. Cheaper alternative to Fibre Channel. Used for SANs (Storage Area Networks) over standard IP networks.
MPLS
Multi-Protocol Label Switching. High performance, high throughput — routes data using short path labels instead of long network addresses. Cost-effective, provides QoS for VoIP, more secure than public internet. Can create VPN connections.
VoIP
Voice over IP — converts analog voice to digital signals over TCP/IP. Lacks authentication mechanisms — vulnerable to toll fraud, eavesdropping, vishing, SPIT (Spam over Internet Telephony). Performance issues: Latency (fixed delay) and Jitter (variable delay). Direct Inward System Access (DISA) exploited by phreakers.
SDN — Software Defined Networking
Separates the infrastructure layer from the control layer (network virtualisation). Makes organisations vendor-independent. Centralised network management. Enables dynamic, programmable network configuration.
CDN — Content Delivery Network
Collection of resources deployed in data centres across the internet to provide low latency and high performance. Caches content geographically close to users. Layer 3 concept. Examples: Cloudflare, Akamai, AWS CloudFront.

WAN technologies
Circuit switching
Dedicated channel created between two parties — consistent connection, all data follows same path. Examples: PSTN, ISDN, DSL, T-carriers. Disadvantages: backdoor risk, slow, vulnerable to war-dialing. Defence: dial-back systems, caller ID restriction, modem tone after 4+ rings.
Packet switching
Message broken into packets, each finds its own route to destination. More efficient use of bandwidth. Technologies: X.25 (low performance), Frame Relay (uses CIR — Committed Information Rate), ATM (53-byte cells — cell switching), VOIP, MPLS, cable modems.
PVC vs SVC
PVC (Permanent Virtual Circuit) = dedicated leased line, always ready. Like a walkie-talkie radio channel. SVC (Switched Virtual Circuit) = dial-up connection established on demand. Like a ham radio that must call first. Frame Relay uses PVC.
ISDN
Integrated Services Digital Network. Fully digital telephone network supporting voice and data. BRI (Basic Rate Interface) = 2B + 1D channels. PRI (Primary Rate Interface) = 23B + 1D channels. ADSL is faster than ISDN.
Firewall generations
1st generation
Packet filter
  • Uses ACLs (rules)
  • Not stateful
  • Inspects Layer 3 (IP, ports)
  • Cannot block viruses
  • No application inspection
  • Fast but limited
2nd generation
Application-level (proxy)
  • Works at Layer 7
  • Deep packet inspection
  • Logging + auditing
  • Extra security layer
  • Slower — inspects every packet
  • Also called proxy firewall
2nd generation
Circuit-level (proxy)
  • Works at Layer 5
  • Monitors TCP handshake
  • SOCKS is common implementation
  • Used between trusted partners
  • Does not inspect content
3rd generation
Stateful inspection
  • Works at Layers 3 & 4
  • Tracks connection state table
  • Blocks unsolicited replies
  • Content-dependent access control
  • Can DoS itself — fills state table
  • Disrupts active sessions on reboot
Bastion host
Hardened server exposed to the internet — designed to take abuse. Stripped of all non-essential services. Sits in the DMZ. Acts as the first line of defence before internal networks.
Screened subnet (DMZ)
Area between two firewalls — outer firewall faces the internet, inner firewall protects internal network. Public-facing servers (web, email, DNS) placed here. Compromising the DMZ does not give access to internal network.
NAT — Network Address Translation
Hides internal IP addresses from external networks — Layer 3. Static NAT: one internal IP maps to one external IP (1:1). Dynamic NAT: multiple internal IPs share a pool of external IPs (many:many). PAT/Overloading: many internal IPs share ONE public IP using different port numbers (many:1). PAT disadvantage: single point of failure.
VLAN security
VLANs logically segment a network without changing physical topology. Provides broadcast isolation cheaply (vs routers). Layer 2 switch provides proper VLAN isolation. Layer 3 switch required for inter-VLAN communication. VLAN hopping = attack bypassing VLAN isolation.
IPSec — Internet Protocol Security
IPSec works at Layer 3. Standard architecture for VPN. Provides P A I N (Privacy · Authentication · Integrity · Non-repudiation). Sets up a secure channel between two parties.
AH — Authentication Header
Provides: Authentication, Integrity, and Non-Repudiation (P A I N). Prevents replay attacks. Does NOT provide confidentiality/encryption. Used when you need to verify sender identity without encrypting content.
ESP — Encapsulating Security Payload
Provides: Confidentiality (encryption) + limited authentication. More commonly used than AH. ESP provides some authentication but not to the same degree as AH. Encrypts the payload. Can be used alone or with AH.
Tunnel mode vs Transport mode
Tunnel mode: entire original IP packet is encapsulated — more secure, used for VPNs between networks. Transport mode: only the payload is encapsulated — better performance, used for host-to-host communications. Tunnel = security priority. Transport = performance priority.
Security Association (SA)
Unique identifier of a secure IPSec connection. Identified by: Destination Address + Security Parameter Index (SPI). SA is simplex (one-way) — a two-way channel requires TWO Security Associations.
ISAKMP
Internet Security Association Key Management Protocol. Functions: Authenticate communicating parties, Create and manage Security Associations, Provide key generation mechanism, Protect against threats. Oakley is used for key management within ISAKMP (uses Diffie-Hellman).
IKE — Internet Key Exchange
Replaced SKIP (Simple Key Management for IP). Used to establish Security Associations and exchange cryptographic keys for IPSec. IKEv2 is the current standard — more efficient, supports MOBIKE for mobile devices.

Remote access authentication protocols
RADIUS
Remote Authentication Dial-In User Service. RFC 2865. Centralised authentication for remote connections. Uses UDP on Port 1812 (auth) / 1813 (accounting). Encrypts only the password in the access-request packet. Commonly used for Wi-Fi authentication and network access control.
TACACS+
Terminal Access Controller Access Control System Plus. Cisco-introduced, now open public protocol. Uses TCP on Port 49. Encrypts the ENTIRE packet (unlike RADIUS). Separates Authentication, Authorisation, and Accounting into distinct functions. Preferred for network device administration.
CHAP
Challenge Handshake Authentication Protocol. Used over PPP. Encrypts user ID and password. Protects against replay attacks. Reauthenticates periodically. More secure than PAP.
PAP
Password Authentication Protocol. Transmits user ID and password in clear text. Exam tip: There are technically no attacks against PAP because everything is already in cleartext — there is nothing to break.
EAP
Extensible Authentication Protocol. Framework that supports any type of authentication. PEAP (Protected EAP): encapsulates EAP inside a TLS tunnel for security. LEAP (Lightweight EAP): Cisco proprietary, broken by ASLEAP attack. EAP-TLS: strongest — mutual certificate-based auth.
PPP
Point-to-Point Protocol. Full Duplex. Supports CHAP and PAP. Multi-vendor interoperability. Replaced SLIP (Serial Line Internet Protocol — no error correction/detection). Used for dial-up and DSL connections.

Wireless encryption protocols
WEP — Wired Equivalent Privacy
64-bit and 128-bit encryption using RC4 stream cipher. Weak 24-bit Initialization Vector (IV) transmitted in cleartext. Easily crackable — broken in minutes. Only option for 802.11b devices. Shared authentication passwords. Do NOT use.
WPA — Wi-Fi Protected Access
Introduced TKIP (Temporal Key Integrity Protocol) to overcome WEP weaknesses. Still uses RC4 stream cipher underneath. Stronger IV than WEP. Interim fix while WPA2 was being developed. No longer considered secure.
WPA2 — Most secure
Uses AES block cipher with CCMP (Counter Mode Cipher Block Chaining Message Authentication Code Protocol). Not backward compatible with WEP. Two modes: Personal (PSK — pre-shared key) and Enterprise (802.1X/EAP — individual user credentials). Current gold standard.
Wireless security threats
War Driving: scanning for open Wi-Fi networks from a vehicle. Rogue Access Points: attacker sets up an unauthorised AP to intercept traffic (MITM). Air Snarfing: wireless packet sniffing. Evil Twin: fake AP mimicking legitimate SSID. Bluejacking: sending unsolicited messages via Bluetooth. Bluesnarfing: copying data from a Bluetooth device. Bluebugging: full phone control via Bluetooth.
Bluetooth attacks
Bluejacking: sends SPAM messages to nearby Bluetooth devices. Bluesnarfing: copies information from a remote device without consent. Bluebugging: most serious — allows full use of the phone including making calls and eavesdropping. Countermeasures: disable discovery mode, disable automatic pairing.
Network attacks & countermeasures
DoS / DDoS
Sends packets beyond bandwidth capacity. DDoS uses botnets. Countermeasure: firewall, load balancer, third-party DDoS mitigation, null routing.
SYN Flood
Sends SYN packets without completing the 3-way handshake — fills the connection table. Layer 4 attack. Countermeasure: SYN cookies, firewall rate limiting.
Smurf Attack
Sends ICMP echo requests to network broadcast address with spoofed source IP — all hosts reply to victim. DDoS using ICMP. Countermeasure: disable directed broadcasts.
Fraggle Attack
Like Smurf but uses UDP packets. Layer 4 attack. Countermeasure: block UDP broadcast traffic at router/firewall.
Ping of Death
Sends oversized ICMP packets that violate the maximum transmission unit (MTU) — crashes the target. Exploits ICMP at Layer 3.
Teardrop
Sends fragmented packets in an order that cannot be properly reassembled — crashes the OS. Exploits fragment reassembly code.
Loki
Covert channel using ICMP — hides data inside ICMP echo packets to exfiltrate data through firewalls that allow ping traffic.
Session Hijacking
Captures an authenticated session to steal credentials or take over the session. Countermeasure: encrypted sessions (TLS), session tokens, re-authentication.
ARP Poisoning / Spoofing
Inserts false MAC address into ARP cache — redirects traffic to attacker (MITM). Countermeasure: monitor ARP cache, use IDS, dynamic ARP inspection.
DNS Poisoning
Corrupts DNS cache so hostname resolves to attacker's IP (Pharming). Countermeasure: DNSSEC, validate DNS responses.
DNS Spoofing
Attacker sends false DNS replies. Resolution: upgrade to DNSSEC which signs DNS responses cryptographically.
Man-in-the-Middle
Attacker intercepts and potentially modifies communication between two parties. Countermeasure: mutual authentication, PKI, certificate pinning, TLS.
Sniffing / Eavesdropping
Listening to network traffic — captures credentials, data. Countermeasure: encryption (TLS, SSH, VPN), switch instead of hub (limits broadcast domain).
War Dialing
Dials random phone numbers to identify modems behind them. Countermeasure: dial-back systems, caller ID restriction, modem tone after 4+ rings.
Replay Attack
Intercepts valid packet and retransmits later. Countermeasure: timestamps, nonces, sequence numbers, one-time authentication tokens (OTP).
Hyperlink / URL Spoofing
Displays deceptive link — redirects to malicious site. Clickjacking redirects user clicks. Countermeasure: verify hyperlinks before clicking, use URL inspection tools.

Secure communication protocols
SSL / TLS
SSL (Secure Sockets Layer) — protects communication between web server and browser. TLS (Transport Layer Security) — stronger replacement for SSL, better authentication and encryption. Supports 2-way mutual authentication using digital certificates. Can be implemented at Layer 3 (OpenVPN), can encrypt UDP and SIP. Spans Layers 4–7.
SSH — Secure Shell
Replaces Telnet and rlogin for remote shell access. Port 22. Provides encrypted terminal sessions, file transfer (SFTP/SCP), and port forwarding. Uses public key cryptography for authentication. Essential for secure server administration.
S/MIME
Secure/Multipurpose Internet Mail Extensions. Uses RSA and X.509 certificates. Provides P A I N for email. Two types: Signed (P A I N — authentication, integrity, non-repudiation) and Enveloped (P A I N — confidentiality). Most enterprise email security standard.
PGP — Pretty Good Privacy
Uses IDEA symmetric algorithm (PGP is a good IDEA). Web of trust model rather than PKI hierarchy. Provides P A I N for email. Encrypt with recipient's public key, sign with sender's private key. Used for personal email encryption — less common in enterprise.
Link vs End-to-End encryption
Link Encryption: encrypts everything including headers (tunnel mode) — slow but secure, works on lower OSI layers, decrypts at each hop. End-to-End Encryption: encrypts only payload (transport mode) — fast, higher OSI layers, data remains encrypted throughout. TLS = end-to-end. VPN tunnel = link encryption.
DKIM / SPF / DMARC
SPF (Sender Policy Framework): verifies the sending mail server is authorised for the domain. DKIM (DomainKeys Identified Mail): cryptographic signature that proves email wasn't altered in transit. DMARC (Domain Message Authentication Reporting and Conformance): policy layer built on SPF + DKIM — filters spoofed messages, generates reports. All three together are essential email anti-spoofing controls.
SET — Secure Electronic Transaction
Uses RSA and DES to secure credit card transactions over the internet. Developed by Visa and Mastercard. Provides P A I N. Largely superseded by TLS-based payment systems but still referenced in CISSP.
SRPC — Secure Remote Procedure Call
Authentication service that prevents unauthorised code execution on a remote system. Secures RPC communications — used in distributed computing environments where processes call functions on remote systems.

Virtualisation & network security boundaries
Security boundary
Line of intersection between any two areas, subnets, or environments with different security requirements. Created using data classification, logical segmentation (VLANs), and physical separation. Every boundary crossing must be monitored and controlled.
Virtual networking
SAN (Storage Area Network): dedicated high-speed network for storage devices. SDN (Software Defined Networking): makes organisations vendor-independent by separating network control from data forwarding. Virtual Desktop Infrastructure (VDI): extends virtualisation concept to user desktops.
Network security controls
Transparency: security mechanisms invisible to end users. Integrity verification: hashing confirms data not altered in transit. Transmission mechanism: logs all transmission records for auditing. IDS/IPS: detects and/or blocks suspicious traffic patterns. SPAN port: copies all switch traffic to a monitoring device.
Technology convergence
Tendency for different technology solutions to evolve and merge over time. Examples: smartphones combining phone + camera + GPS + computer. Security concern: convergence increases attack surface — a single device compromise can affect multiple functions.
